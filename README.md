Lords of the Fallen — Character Creation Tool

A simple ASP.NET Core MVC application that allows users to create and manage custom character builds inspired by Lords of the Fallen.
Users can enter character names, choose a class and ancestry, and assign starting attributes.

Features
Create characters with:
First & Last Name
Class selection
Ancestry selection
Attribute assignment (Strength, Agility, Endurance, Vitality, Radiance, Inferno)
Fully model-validated form using data annotations
Razor-based UI
Entity Framework Core model with auto-incrementing CharacterId
